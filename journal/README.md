# Журнал

День — `journal/ГГГГ/ГГГГ-ММ-ДД.md`, неделя — `journal/ГГГГ/ГГГГ-Wнн.md`.
Создаются командами `./tools/life today` и `./tools/life week` по шаблонам из `templates/`.
Как вести — [день](../processes/day.md) и [неделя](../processes/week.md).

Журнал — сырой материал. Переносимый вывод из него переезжает в [знания](../knowledge/README.md),
принятое правило — в его [сферу](../areas/README.md), работа с результатом — в [дела](../cases/README.md).
