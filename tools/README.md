# Инструменты

`./tools/life` — команды пространства. Нужен только `python3` (есть в macOS), без установки пакетов.

| Команда | Что делает |
| --- | --- |
| `./tools/life today` | Создаёт файл сегодняшнего дня, если его нет |
| `./tools/life week` | Создаёт файл текущей недели |
| `./tools/life new case\|knowledge\|decision\|post SLUG --title '...'` | Создаёт запись по шаблону; дело попадает в список дел |
| `./tools/life check` | Ищет битые ссылки, незаполненные места шаблонов и дела без строки в списке |
| `./tools/life search 'текст'` | Ищет текст по всем заметкам |

Проверка самих команд: `python3 -m unittest discover -s tools/tests`.
