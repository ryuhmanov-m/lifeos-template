# Развитие системы

Результат — пространство, которое стало удобнее, без лишнего.

1. Назови конкретное трение: что мешало, сколько раз, что владелец делал вместо этого.
2. Найди самое маленькое изменение: поправить строку процесса, шаблон, договор, добавить команду.
   Новый раздел или инструмент — только если без него повторяется ручная работа.
3. Предложи владельцу одной–двумя строками, сделай после согласия, выполни `./tools/life check`.
4. Удаляй то, чем не пользуются месяц: пустую сферу, процесс без вызовов.
