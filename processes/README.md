# Процессы

Выбери маршрут по нужному результату. Короткую понятную просьбу выполни сразу,
без маршрута: ответ или правка, проверка, одна строка итога.

| Результат | Маршрут |
| --- | --- |
| Настроить пространство под владельца | [Первый запуск](start.md) |
| Разобрать входящие, мысль, ссылку, голосовую заметку | [Входящие](capture.md) |
| Спланировать день или подвести его итог | [День](day.md) |
| Подвести итог недели и спланировать следующую | [Неделя](week.md) |
| Написать, отредактировать или опубликовать пост | [Пост](post.md) |
| Довести работу до результата: переезд, запуск, покупка | [Дело](case.md) |
| Выбрать между вариантами | [Решение](decide.md) |
| Узнать то, чего не знаем | [Исследование](research.md) |
| Сохранить урок, чтобы он пригодился | [Опыт](learn.md) |
| Улучшить само пространство | [Развитие системы](evolve.md) |

Общее для всех маршрутов:
- Перед ответом сверься с [владельцем](../me.md) и [направлением](../direction.md).
- Внешний эффект — публикация, сообщение человеку, оплата, удаление — только по явной
  просьбе в этом разговоре. Подготовь всё и спроси одной строкой.
- Итог: что сделано, где лежит, что осталось; длинное — в файл, в ответе ссылка.
- После правки файлов: `./tools/life check`.
