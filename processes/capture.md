# Входящие

Результат — пустые [входящие](../inbox.md): каждая запись лежит у своего владельца или удалена.

Для каждой записи выбери одно:

| Что это | Куда |
| --- | --- |
| Сделать за пару минут | Сделай или предложи сделать сейчас |
| Задача на конкретный день | Раздел «Главное» в дне этого дня |
| Работа из нескольких шагов с результатом | Новое или существующее [дело](../cases/README.md) |
| Идея поста | [Идеи](../content/ideas.md) |
| Проверенный вывод | [Знание](../knowledge/README.md), см. [опыт](learn.md) |
| Принятое правило («больше не …») | Раздел «Правила» своей [сферы](../areas/README.md) |
| Может быть когда-нибудь | Раздел «Когда-нибудь» в конце входящих |
| Не нужно | Удали |

Голосовую или длинную заметку сначала перескажи в 1–3 строки и уточни, если смысл неясен.
Итог владельцу — таблица «запись → куда» одной строкой на запись.
