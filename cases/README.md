# Дела

Дело — работа с результатом: переезд, запуск рубрики, ремонт, подготовка к марафону.
Папка `cases/<slug>/README.md`, материалы рядом. Создание: `./tools/life new case SLUG --title '...'`.
Строка в списке — название, дата и одна фраза о состоянии; обновляй её при изменении.
