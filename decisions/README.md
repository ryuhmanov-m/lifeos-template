# Решения

Решение — осознанный выбор, который ограничивает дальнейшие действия: «пишу только в Telegram
до весны», «не беру проекты без предоплаты». Записывается, когда к выбору захочется вернуться
или его придётся объяснить. Создание: `./tools/life new decision SLUG --title '...'`.
Решение действует, когда владелец его принял; до этого оно «предложено».
