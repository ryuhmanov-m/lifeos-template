# Сферы

Сфера — постоянная часть жизни без даты окончания: её поддерживают, а не завершают.
Дело с результатом и сроком живёт в [делах](../cases/README.md) и ссылается на сферу.

Лишнюю сферу удали, недостающую добавь по образцу. Хорошая сфера отвечает на три вопроса:
куда я хочу прийти, какая норма считается «всё в порядке», какой ритм её поддерживает.
