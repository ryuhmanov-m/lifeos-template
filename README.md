# LifeOS

Личное пространство, которое ведёт AI-агент: дневник, цели, дела, заметки, блог.
Ты разговариваешь с агентом обычными словами, а он раскладывает всё по папкам, помнит
твои правила и пишет твоим голосом. Всё хранится в обычных текстовых файлах у тебя на компьютере.

## Начать (15 минут)

1. Поставь [Claude Code](https://claude.com/claude-code) (или Codex) и войди в аккаунт.
2. Скопируй эту папку к себе, например в `~/LifeOS`, и открой её в терминале:
   `cd ~/LifeOS && claude`. Если папка пришла как Git-репозиторий, сначала отвяжи её
   от чужого адреса: `git remote remove origin`.
3. Напиши агенту: «Давай первый запуск» (или `/start`). Он проведёт интервью примерно
   на полчаса — можно частями — и заполнит профиль, цели, сферы жизни и голос блога.

## Каждый день

| Скажи | Что будет |
| --- | --- |
| «Доброе утро» или `/today` | Три главных дела на день из твоих целей и вчерашнего хвоста |
| «Итог дня» или `/today` вечером | Короткий итог, перенос несделанного |
| Любая мысль, ссылка, голосовая расшифровка или `/capture` | Разложит по местам: задача, идея поста, заметка |
| «Напиши пост про …» или `/post` | Черновик твоим голосом; публикуешь ты |
| «Итог недели» или `/week` (раз в неделю) | Что сдвинулось, где просело, три результата на следующую |
| «Помоги решить …» | Варианты, сравнение, рекомендация; выбор твой |

Можно просто разговаривать: агент сам найдёт нужный маршрут.

## Что внутри

| Файл или папка | Что это |
| --- | --- |
| `me.md` | Кто ты и как с тобой работать. Самый важный файл: агент читает его первым |
| `direction.md` | Фокус на ближайшие месяцы: до трёх целей и от чего отказался |
| `areas/` | Сферы жизни: блог, здоровье, деньги, работа, люди, рост |
| `inbox.md` | Всё неразобранное |
| `cases/` | Дела с результатом: «переехать», «запустить рубрику» |
| `knowledge/` | Проверенные выводы: что работает у тебя и в блоге |
| `decisions/` | Важные выборы и почему они сделаны |
| `journal/` | Дни и недели |
| `content/` | Блог: голос, идеи, черновики, опубликованное |
| `processes/` | Инструкции для агента: как делать каждый вид работы |
| `standards/`, `templates/`, `tools/` | Правила, формы записей и команды |

## Три правила, которые делают систему полезной

1. **Поправляй агента.** «Так я не говорю», «не предлагай больше трёх дел» — он запишет правило
   в `me.md` или голос, и в следующий раз сделает правильно. Система учится только на поправках.
2. **Раз в неделю — обзор.** Без него цели и дела расходятся с жизнью за пару недель.
3. **Убирай лишнее.** Не пользуешься сферой или разделом месяц — скажи агенту удалить.

## Безопасность

Пароли, токены и номера карт сюда не пиши. Если хранишь копию в GitHub — только приватный
репозиторий. Совсем личное клади в `private/`: эта папка не попадает в историю Git.
История правок в Git: любую ошибку агента можно откатить.

## Откуда это

Устройство перенесено из рабочего пространства, в котором агенты ведут разработку продукта:
навигация для агента вместо длинных инструкций, у каждого смысла один адрес, процессы
по результату, знания отдельно от дневника, решения отдельно от знаний, поправки владельца
сразу становятся правилами. Инженерная механика (релизы, CI, репозитории кода) убрана.
Как развивать само пространство — [развитие системы](processes/evolve.md).
