# Письмо

Тексты пространства читает агент. Пиши так, чтобы он сделал правильно с первого раза.

- Минимум контекста, достаточный для верного действия. Сначала отбери содержание, потом сокращай.
- Процесс — повелительно: «прочитай», «запиши», «спроси». Шаг: условие → действие → результат.
- Навигация — «нужно → адрес». Объяснения живут в справке, а не в навигации.
- «Всегда» и «никогда» — только для настоящих границ. Остальное — «если X, сделай Y».
- Пример помогает, когда без него правило понимают по-разному.
- Правило с причиной лучше правила без неё: агент перенесёт причину на новый случай.
- Короче — не всегда лучше: не удаляй условие, без которого действие станет неверным.

Ответ владельцу — по [договору с владельцем](../me.md#как-со-мной-работать).
