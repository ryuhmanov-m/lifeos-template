# Размещение

У каждого смысла один адрес. Остальные места ссылаются на него, а не повторяют.

| Материал | Где |
| --- | --- |
| Кто владелец и как с ним работать | `me.md` |
| Текущий фокус и отказы | `direction.md` |
| Постоянная часть жизни | `areas/<сфера>.md` |
| Неразобранное | `inbox.md` |
| Работа с результатом | `cases/<slug>/README.md`, материалы рядом |
| Проверенное понимание | `knowledge/<сфера>-<суть>.md` |
| Принятый выбор | `decisions/ГГГГ-ММ-ДД-<slug>.md` |
| День и неделя | `journal/ГГГГ/` |
| Блог | `content/` |
| Способ получить результат | `processes/` |
| Формы записей | `templates/` |
| Команды | `tools/` |
| Чувствительное, не для Git | `private/` (игнорируется Git) |
| Временное | `.local/` (игнорируется Git) |

Новая папка или вид записи появляется, когда старых мест не хватает несколько раз подряд,
см. [развитие системы](../processes/evolve.md).
Имена файлов — латиница, строчные, через дефис. Ссылки — относительные Markdown-ссылки.
